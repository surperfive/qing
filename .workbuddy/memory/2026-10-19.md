## 「我的功能」展开动画改成真动画
- 背景：原展开区用的 `animate-in fade-in duration-200` 是 tailwindcss-animate 的类，项目没装该插件 → 完全是瞬间出现（用户反馈要"丝滑"）。
- 改法（`MePage.tsx`）：
  - 引入 `motion/react` 的 `AnimatePresence / motion / useReducedMotion`，模块级 `EASE_OUT = [0.22,1,0.36,1]`。
  - 展开区改为 `motion.div`：`height: 0 → auto`、opacity 0→1，高度 0.42s / 透明度 0.24s 同为 ease-out；外层 `overflow-hidden`，`AnimatePresence initial={false}`。
  - 子项 `motion.button` 错峰上浮（`y:10→0`、opacity，delay 0.06 + i*0.05，0.32s）。
  - 「展开全部/收起」胶囊改 `motion.button layout + whileTap`，文字宽度变化平滑过渡；箭头改为单个 ChevronDown 旋转 180°（原来的 ChevronUp/Down 切换太硬），并补 `aria-expanded / aria-controls`。
  - 全部动画读 `useReducedMotion()`，reduced-motion 下 duration=0。
- 验证：Playwright 每 50ms 采样高度，展开 10→51→82→94→98→100，收起 96→44→16→7→2→0，无 console 错误，`tsc --noEmit` exit=0。
- 经验：本项目未安装 tailwindcss-animate，`animate-in`/`fade-in`/`zoom-in` 这类类名一律无效，要做动画请直接用已装的 `motion`。
