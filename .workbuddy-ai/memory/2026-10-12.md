## 抽卡页顶部条不吸顶 —— 根因是祖先的 `overflow-hidden`

用户反馈「但是现在没有在吸顶」。`GachaPage.tsx:642` 的 header 写了 `sticky top-0`，
但**从来没生效过**。

### 根因
`position: sticky` 相对于**最近的滚动祖先**定位，而 `overflow: hidden`
**会创建一个滚动容器**。结构是：

```
div.overflow-y-auto          ← 真正的滚动容器
└─ #gacha-page-root          ← overflow-hidden，成为更近的「滚动容器」
   └─ header.sticky top-0    ← 粘在这个从不滚动的容器上 = 等于没粘
```

`#gacha-page-root` 高度 = 内容全高（1042px），自身 `scrollTop` 恒为 0，
header 粘上去毫无效果。

### 修法
`#gacha-page-root` 的 `overflow-hidden` → **`overflow-clip`**。
`overflow: clip` 裁剪行为一致，但**不创建滚动容器**，sticky 于是继续向上
找到真正的滚动祖先 `div.overflow-y-auto`。降级也安全：万一浏览器不支持
`overflow: clip`，溢出会被外层 `div.flex-1.overflow-hidden`（`App.tsx:283`）兜住。

实测：
| overflow | 滚动 520px 后 header 视口 top |
|---|---|
| `hidden`（改前） | **-520**（跟着滚走了） |
| `clip`（改后） | **0**（吸顶） |

### 顺带排查
全项目 `sticky` 只有 5 处：

- `HeaderBar.tsx:21` —— `sticky` 是**死代码**：它在 `App.tsx:291` 渲染于 `main`
