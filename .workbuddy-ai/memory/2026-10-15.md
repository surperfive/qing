## 全站按压态/过渡统一 + 详情页选中副标题变绿

### 1) 按压态统一（用户：「把按钮的选中效果统一一下」）

**改前**：5 种不同按压缩放在做同一件事 —— `active:scale-95`(48) / `scale-98`(10) /
`scale-90`(6) / `scale-[0.98]`(10) / `scale-[0.99]`(4)；另有 44 处可点元素**完全没有反馈**。

**改后**：全站只有两档，共 111 处。

| 元素类型 | 写法 |
|---|---|
| 按钮 / 胶囊 / 图标 / 列表行 / 文字链 | `active:scale-95` |
| 卡片 / 面板 / 整块可点区域 | `active:scale-[0.98]` |

过渡统一为 `transition-{all|colors|transform} duration-200 ease-out`（111 处全带上）。
⚠️ **`duration-300` 全部保留没动** —— 实测 `active:scale` 与 `duration-300` **零重叠**，
那 24 处 300ms 是内容动画（轮播/餐盖/吉祥物），不是按压反馈。

归一用 awk 批处理（先按值归并，再给缺 transition 的补 `transition-all duration-200 ease-out`）。
判据脚本 `scripts/scan-feedback.mjs` —— 找「有 cursor-pointer 但整行无 active:」的元素。

**刻意不改的 7 处**（有理由，别当漏改）：
黑色遮罩(FloatingCart:109) / group 容器且子元素已有 hover(CartPage:136、FloatingCart:139/185/201/215)
/ 轮播 slide(BannerSlider:34) / 餐盖主视觉(GachaPage:812) / 搜索输入框(MenuPage:309)
/ 条件类名里的 flag 而非元素(GiftMascotAnimation:33、MePage:193)

### 2) 详情页选项：选中后副标题变绿

用户给了两张参考图：选中项的副标题（"约450g · 控卡均衡"）要是绿的。
**「主粮基底」本来就是对的**（`isSelected ? 'text-[#54801A] font-bold' : 'text-slate-400'`），
只有「份量规格 / 杯型」漏了。按同一写法补齐 `ProductDetailPage.tsx` 2 处（regular / large）：

```jsx
<div className={`text-[9.5px] font-medium mt-0.5 leading-tight truncate ${size === 'regular' ? 'text-[#54801A] font-bold' : 'text-slate-400'}`}>
```

绿色用 `#54801A`（`--lime-700`，白底 4.7:1 过 AA）—— 不是品牌主色 `#C7F665`（对白仅 1.25:1）。

脚本 `scripts/shot-detail-subtitle.mjs` → `outputs/detail-subtitle/`，
两张分别验证「标准碗选中 / 超大碗选中」，选中绿+加粗、未选中灰。
